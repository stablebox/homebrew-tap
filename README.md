# stablebox/homebrew-tap

Homebrew casks for [StableBar](https://github.com/stablebox/StableBar), a native, configurable menu bar for macOS. Install it with `brew install --cask stablebox/tap/stablebar`. Use the full name: Homebrew only loads casks from taps you trust, so after a plain `brew tap stablebox/tap`, `brew install --cask stablebar` fails until you run `brew trust stablebox/tap`. Each stable release of StableBar updates the cask here. StableBar also updates itself, so `brew upgrade` skips it unless you pass `--greedy`. `brew uninstall --cask stablebar` quits StableBar and removes the app. Once Homebrew is done, StableBar 0.19.0 or later undoes what it changed on the Mac, as its own Uninstall does, unless Homebrew installed it again. `--zap` also moves `~/.config/stablebar` to the Trash. Homebrew keeps the uninstall steps a cask had when it was installed, so an install from before this cask change doesn't get this, even after StableBar updates itself: once 0.19.0 is out, run `brew reinstall --cask stablebox/tap/stablebar` once, with the full name for the same reason as installing.
