# stablebox/homebrew-tap

Homebrew casks for [StableBar](https://github.com/stablebox/StableBar), a native, configurable menu bar for macOS. Install it with `brew install --cask stablebox/tap/stablebar`. Use the full name: Homebrew only loads casks from taps you trust, so after a plain `brew tap stablebox/tap`, `brew install --cask stablebar` fails until you run `brew trust stablebox/tap`. Each stable release of StableBar updates the cask here. StableBar also updates itself, so `brew upgrade` skips it unless you pass `--greedy`. `brew uninstall --cask stablebar` quits StableBar and removes the app; once Homebrew is done, StableBar undoes what it changed on the Mac, as its own Uninstall does, unless Homebrew installed it again. `--zap` also moves `~/.config/stablebar` to the Trash.
